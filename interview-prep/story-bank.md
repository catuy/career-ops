# Story Bank — Master STAR+R Stories

This file accumulates your best interview stories over time. Each evaluation (Block F) adds new stories here. Instead of memorizing 100 answers, maintain 5-10 deep stories that you can bend to answer almost any behavioral question.

## How it works

1. Every time `/career-ops oferta` generates Block F (Interview Plan), new STAR+R stories get appended here
2. Before your next interview, review this file — your stories are already organized by theme
3. The "Big Three" questions can be answered with stories from this bank:
   - "Tell me about yourself" → combine 2-3 stories into a narrative
   - "Tell me about your most impactful project" → pick your highest-impact story
   - "Tell me about a conflict you resolved" → find a story with a Reflection

## Stories

### [Design Systems] Building ANII's Government Design System
**Source:** Report #002 — Vercel — Senior Product Designer
**S (Situation):** Uruguay's national innovation agency (ANII) had inconsistent digital interfaces across 15+ platforms serving researchers and institutions.
**T (Task):** Create and maintain a unified design system to bring coherence, accessibility, and scalability across the entire digital ecosystem.
**A (Action):** Over 9 years, built the design system from scratch — defined tokens, components, patterns. Collaborated with multiple development teams. Iterated based on user research with researchers and public servants.
**R (Result):** Uruguay's first government design system. Consistent UX across all ANII platforms. Became a reference for other government agencies.
**Reflection:** Long-term design system work requires patience and stakeholder alignment more than technical brilliance. The hardest part is governance, not components.
**Best for questions about:** Design systems experience, long-term ownership, working with constraints, stakeholder management.

### [Technical Design] UNESCO Ocean Report Card — React Data Viz
**Source:** Report #002 — Vercel — Senior Product Designer
**S (Situation):** UNESCO-IOC needed an interactive report card to visualize global ocean observing data for policymakers and scientists.
**T (Task):** Design and develop the full platform — from information architecture to interactive data visualizations to production React code.
**A (Action):** Led end-to-end: designed the data viz approach, built React components, implemented responsive interactive charts. Worked directly with ocean scientists to translate complex data into clear visual stories.
**R (Result):** Shipped a production React platform that makes global ocean data accessible to non-technical stakeholders.
**Reflection:** Designing for scientific data requires extreme clarity — every pixel of a chart must earn its place. The "designer who codes" advantage was critical here.
**Best for questions about:** Design + code, data visualization, complex technical domains, end-to-end ownership.

### [AI-Native Workflow] Shipping Fast with Claude Code
**Source:** Report #002 — Vercel — Senior Product Designer
**S (Situation):** In recent projects, traditional design-to-handoff workflows created bottlenecks and fidelity loss.
**T (Task):** Integrate AI tools into the design workflow to ship faster while maintaining quality.
**A (Action):** Adopted Claude Code as core workflow tool. Use it for rapid prototyping, code generation, and iteration. Design in Figma, then build in code with AI assistance — eliminating the handoff gap.
**R (Result):** Dramatically faster iteration cycles. Can go from concept to production code in hours rather than days.
**Reflection:** AI doesn't replace design judgment — it amplifies execution speed. The designer still needs to know what good looks like.
**Best for questions about:** AI tools, modern workflow, rapid iteration, v0/Cursor/Claude Code familiarity.

### [Complex UI] ClassWallet Financial Platform Design
**Source:** Report #002 — Vercel — Senior Product Designer
**S (Situation):** ClassWallet is a US fintech handling education funding — complex flows involving multiple user types, compliance requirements, and financial transactions.
**T (Task):** Design intuitive flows for complex financial operations while maintaining compliance and accessibility.
**A (Action):** Defined product strategy, designed multi-step financial flows, built a coherent design system. Collaborated closely with engineering and product teams.
**R (Result):** Streamlined financial flows for education administrators. Design system ensured consistency across the growing platform.

**Best for questions about:** Financial infrastructure, complex UI, design systems, cross-functional collaboration.
